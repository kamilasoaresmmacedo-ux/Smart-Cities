# Smart-Cities
O InovaCity é um projeto voltado às Cidades Inteligentes (Smart Cities), que apresenta como a tecnologia, a inovação e a sustentabilidade podem transformar os ambientes urbanos. Aborda mobilidade inteligente, inteligência artificial, Internet das Coisas (IoT), conectividade e soluções tecnológicas para melhorar a qualidade de vida da população.
